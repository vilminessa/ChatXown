# ChatXown

Оверлей чата Twitch и YouTube поверх других окон Windows. Electron + TypeScript + React.

![status](https://img.shields.io/badge/state-alpha-orange)
![license](https://img.shields.io/badge/license-PolyForm%20Noncommercial-informational)

## Что уже работает

- **Оверлей на весь экран** — одно frameless окно занимает работуArea основного дисплея, без рамки и тени, не занимает место в таскбаре. Чат — прямоугольная область внутри этого окна.
- **Размер и положение чата прямо в оверлее** — область перетаскивается за шапку, меняется за края и углы, кнопки `⌜ ⌝ ⌞ ⌟` прижимают к углу экрана, `▣` растягивает на весь экран. Тулбар лежит внутри области чата (слева внизу, не перекрывает ручки), контур и ручки видны только при наведении и не пропадают во время перетаскивания. Координаты сохраняются в конфиге.
- **Сквозной режим** — по умолчанию включён: клики проходят в игру/приложение под оверлеем, мышь перехватывается только над прямоугольной областью чата (с запасом 12px по краям) и панелью настроек. `Ctrl+Alt+O` выключает сквозной режим — тогда оверлей держит весь экран, и в шапке появляется красный чип «захват всего экрана», а переключение показывает toast. Конфиги, где захват всего экрана был включён до v0.2.2, мигрируются на сквозной режим автоматически.
- **Несколько чатов одновременно** — Twitch и YouTube вперемешку, каждый источник включается/выключается отдельным тумблером, своё имя, цвет и набор эмоутов.
- **Twitch без авторизации** — анонимный IRC по WebSocket (`justinfan`), один коннект на все каналы.
- **YouTube** — живой чат через `youtubei.js`: `@handle`, ID канала, ссылка на канал или конкретный эфир. Канал перепроверяется, когда эфир заканчивается или ещё не начался.
- **Эмоуты Twitch**: нативные + **7TV**, **BTTV**, **FFZ** (канальные и глобальные наборы, кэш на 6 часов). На YouTube — нативные эмодзи/эмоуты канала.
- **Бейджи, цвета ников, /me, sub/resub/subgift/raid, bits**, удаление сообщений (CLEARMSG/CLEARCHAT). Для YouTube — бейджи (автор, мод, участник, ✓) и очистка сообщений/по автору.
- **Модерация Twitch** — удаление сообщения, таймаут на 10 минут и бан прямо из оверлея (Helix API, OAuth Device Code Flow).
- **Панель настроек внутри оверлея** — модальная плашка по центру: источники, эмоты, фильтры по словам/юзерам, шрифт, прозрачность фона, ширина плашек, лимит сообщений, таймстемпы, бейджи, автоскрытие старых сообщений, Twitch-вход, сквозной режим, показ оверлея и опрос курсора. Отдельного окна настроек нет.
- **Трей + горячие клавиши**, конфиг в `%APPDATA%\chatxown\config.json`. Сборка — только portable exe.

## YouTube

Добавьте источник и вставьте одно из:

- `@handle` — например, `@LofiGirl`;
- ID канала вида `UC…`;
- ссылку на канал (`youtube.com/@LofiGirl`, `youtube.com/channel/UC…`, legacy `/c/…` и `/user/…`);
- ссылку на конкретный эфир или видео (`youtube.com/watch?v=…`, `youtu.be/…`, `youtube.com/live/…`).

Если указан канал, ChatXown сам находит текущий live-эфир и подключается к его чату. Когда эфир заканчивается, источник переходит в состояние **не в эфире** и периодически проверяет канал снова. Для видео-ID проверяется, что эфир ещё идёт и чат включён.

Ограничения YouTube: сторонние наборы 7TV/BTTV/FFZ не поддерживают YouTube, поэтому доступны только нативные эмодзи и эмоуты канала. Модерация пока реализована только для Twitch.

## Модерация

1. Создайте приложение на <https://dev.twitch.tv/console/apps>: тип **Public**, OAuth Redirect URL — `http://localhost`.
2. Откройте панель настроек оверлея (`Ctrl+Alt+S`), раздел **Аккаунт Twitch**, вставьте **Client ID** и нажмите **Войти через Twitch**.
3. Введите показанный код на `twitch.tv/activate` и подтвердите доступ.
4. Наведите курсор на сообщение — оверлей перехватит мышь над чатом, и появятся кнопки `⌫` (удалить), `10м` (таймаут) и `Бан` (второй клик подтверждает). Если сквозной режим выключен (`Ctrl+Alt+O`), кнопки доступны в любой точке экрана.

Токены хранятся зашифрованными через `safeStorage` в `%APPDATA%\chatxown\auth.json`. Нужны разрешения `moderator:manage:banned_users` и `moderator:manage:chat_messages`; вы должны быть модератором или владельцем канала.

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl+Alt+O` | Сквозной режим: включён — мышь перехватывается только над областью чата и панелью; выключен — оверлей держит весь экран (в шапке чип «захват всего экрана», переключение показывает toast) |
| `Ctrl+Alt+H` | Скрыть / показать оверлей |
| `Ctrl+Alt+S` | Открыть / закрыть панель настроек |
| `Esc` | Закрыть панель настроек |
| клик по иконке в трее | Скрыть / показать оверлей; двойной клик — панель настроек |

## Ограничения

- Поверх **эксклюзивного fullscreen** оверлей не отображается — это делает только инжект в процесс игры. Используйте borderless / windowed.
- YouTube: только нативные эмоуты, модерация недоступна; при отключённом чате источник показывает ошибку.
- Пока сквозной режим включён, кнопки модерации, тулбар и перетаскивание активны, когда курсор внутри области чата (или над тулбаром/ручками — они тоже внутри области) и над панелью настроек; вне этих зон клики уходят в приложение под оверлеем. Зоны считаются по координатам, а не по DOM, поэтому «зазоры» между элементами не разрывают захват; после выхода из зоны перехват отпускается через ~500ms, чтобы ручки не мигали при перетаскивании. `Ctrl+Alt+O` выключает сквозной режим, и тогда перехватывается весь экран.
- Оверлей занимает основной дисплей; на втором мониторе он не появляется.

## Разработка

```bash
npm install
npm run dev          # запуск с HMR
npm run build        # сборка в out/
npm test             # юнит-тесты парсера, источников и маппинга YouTube
npm run typecheck    # tsc по main и renderer
```

Windows-сборка:

```bash
npm run dist         # portable exe в release/
npm run dist:dir     # распакованная сборка в release/win-unpacked
```

Готовые exe публикуются автоматически: создайте и запушьте тег `v0.2.2` — GitHub Actions соберёт portable-версию и приложит её к релизу. Установщика (NSIS) нет: программа запускается как один exe, конфиг по умолчанию пишется в `%APPDATA%\chatxown`.

Полезные переменные окружения:

```bash
CHATXOWN_DEBUG=1        # логировать события чата, статусы и консоль renderer в stdout
CHATXOWN_DEMO=1         # синтетические сообщения для проверки вёрстки
CHATXOWN_CAPTURE=path.png  # снять скриншот окна через 9 секунд
CHATXOWN_PROBE=path.png    # прогнать UI-сценарий: наведение, скрытие/показ, тулбар внутри чата, drag, панель настроек, чат на весь экран
```

### Структура

```
src/main/           главный процесс (окно на весь экран, трей, хоткеи, конфиг)
src/main/chat/      менеджер источников
  twitch/           IRC-клиент, парсер, маппинг событий
  youtube/          резолв эфира, live chat клиент, маппинг событий
src/main/twitch/    OAuth (device flow), Helix API, модерация
src/preload/        contextBridge API
src/renderer/       overlay: лента, область чата с drag/resize, модальная панель настроек
src/shared/         общие типы, IPC-каналы, геометрия области чата
scripts/            тесты, генератор иконки, probe IRC/YouTube, сборка youtubei.js
.github/workflows/  CI (typecheck+tests) и сборка exe на тегах v*
```

## Технические заметки

- Twitch: `wss://irc-ws.chat.twitch.tv:443`, `CAP REQ :twitch.tv/tags twitch.tv/commands`, анонимный `justinfan*`.
- Эмоуты: `7tv.io/v3`, `api.betterttv.net/3`, `api.frankerfacez.com/v1`. Приоритет при коллизии имён: 7TV → BTTV → FFZ → нативные.
- YouTube: `youtubei.js` (ESM, загружается динамическим import), `getLiveStreams()` для поиска эфира, `getInfo().getLiveChat()` для чата; неизвестные узлы парсера игнорируются. Для упакованной сборки библиотека собирается esbuild в один `resources/youtube.mjs`, чтобы не зависеть от ESM/asar.
- Сборка: `electron-builder`, цель `portable` x64, иконки из `resources/`, `resources/resources` внутри пакета.
- Модерация: Helix `DELETE /moderation/chat`, `POST /moderation/bans`, `DELETE /moderation/banned`; авторизация — Device Code Flow без client secret.
- Окно: `transparent`, `frame: false`, всегда на `workArea` основного дисплея (`screen-saver` уровень, пере привязке к дисплею при его изменении), `setIgnoreMouseEvents(true, { forward: true })`. Renderer сообщает main процессу `{ interactive, focus }` по координатам курсора: main включает/выключает перехват мыши и `setFocusable` (клавиатура доступна только пока открыта панель настроек). На изменениях видимости состояние применяется форсированно — сначала `show`, потом `setIgnoreMouseEvents`, с «противоположным» переключателем перед целевым значением, иначе Windows оставляет `WS_EX_TRANSPARENT` и окно после скрытия/показа глухо к кликам. Когда `overlay.pollCursor` включён, main дополнительно каждые 120ms читает `screen.getCursorScreenPoint()` и включает перехват сам, если курсор внутри зоны чата; решение renderer остаётся приоритетным для перетаскивания.
- Область чата хранится в `config.json` как `overlay.chat` в координатах окна (DIP), `null` — на весь экран; старые `overlay.bounds` мигрируют в `overlay.chat`. Конфиг верси 2: `overlay.clickThrough` по умолчанию включён, и записи более старой версии (где оверлей держал весь экран) при первом запуске переводятся на сквозной режим; `overlay.pollCursor` по умолчанию выключен и включается только тумблером в панели.
